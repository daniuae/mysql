Assignment: Two-Number Calculator

Goal
Write a program that simply asks the user for two numbers, adds them together, and displays the result.

Step 1: Planning Logic (Pseudocode)
* Focus: Planning Logic
1. Write the pseudocode (the steps in plain English) for the program to:
* Get the first number from the user.
* Get the second number from the user.
* Calculate the sum of the two numbers.
* Display the final result.

Step 2: Programming Basics & Syntax
* Focus: Variables, Data Types, Input, Operators
1. Input and Variables: Write the code to:
* Declare two numeric variables, numA and numB.
* Prompt the user to enter a value for numA.
* Prompt the user to enter a value for numB.
1. Operators: Declare a third variable, sumResult, and use the addition operator (+) to calculate the sum of numA and numB.

Step 3: Control Structures (If/Else)
* Focus: Simple If/Else
1. Decision Logic: Write a basic If/Else block using the sumResult:
* If sumResult is greater than 100, print: "Result is a large number."
* Otherwise (Else), print: "Result is a small number."

Step 4: Output
* Focus: Displaying Data
1. Final Display: Print a single, clear message that shows the final calculated sumResult.
